# videos/ — 成片目录

这里存放**精选成片**（渲染完成的教学动画视频），供读者和评审直接在线查看，无需本地渲染。

## 与 media/ 的区别

- `media/` 是 Manim 渲染的原始输出目录，体积大、可随时再生成，已被 .gitignore 忽略，**不要提交**；
- `videos/` 是人工精选的成片，随仓库发布，**可以提交**（GitHub 网页可直接播放）。

## 命名规范

`chNN_场景名.mp4`，例如 `ch15_BubbleSortScene.mp4`。

## 提交建议

- 单文件尽量控制在 10 MB 以内（1080p、60 秒以内通常满足）；
- 每个成片在下方清单中登记一行，注明对应章节与场景。
