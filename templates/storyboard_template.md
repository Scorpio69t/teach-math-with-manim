# 微课分镜表模板

> 《Manim，让数学看得见》第 20 章配套模板。一节微课开拍前先填这张表——
> 填表的过程就是把"我要讲什么"翻译成"观众第几秒看到什么、听到什么"。
> 用法：复制本表，逐行填写；填完后整节课的总时长、停顿位、素材缺口一目了然。

| 序号 | 时段 | 画面（观众看到什么） | 台词（逐字稿，写到"的、了、呢"） | 动画来源（场景文件 / 片段区间） | 停顿点 | 备注 |
|------|------|----------------------|----------------------------------|--------------------------------|--------|------|
| 1 | 0:00–0:30 | | | | | |
| 2 | 0:30–1:00 | | | | | |
| 3 | | | | | | |
| … | | | | | | |

## 填写纪律

1. **时段先粗后细**：第一遍只填"导入 / 新授 / 停顿提问 / 小结"四大段的时长，
   确认总时长在预算内（微课建议 6–10 分钟），再逐段细分；
2. **台词写逐字稿**：不是提纲，是你真的会说的那句话——包括口头禅。
   只有逐字稿能暴露"这一段要 40 秒，可动画只有 12 秒"这类节奏错配；
3. **停顿点单独一列**：每一处"让学生想一想"都必须落在表上，
   并和动画里的 wait 节拍一一对齐（第 1 章的铁律：每一拍等得起一句讲解）；
4. **动画来源写清场景名与片段区间**：分段渲染（`manim -n 起始,结束`）时
   直接照抄此列，不多渲一秒；
5. **备注列放风险**：哪一段动画还没做、哪一句台词没把握、哪里要插板书照片。
